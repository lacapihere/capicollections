01 — Contexto

El proyecto

IPRAF es un sistema analítico estructurado para la reacreditación y actualización de licencias profesionales. Su contenido, metodología, clasificación y lógica editorial ya existen y son propiedad del cliente — no es un curso tradicional ni un banco convencional de preguntas.

Nuestro rol como proveedor tecnológico es transformar esa estructura existente en una plataforma web funcional, propietaria y escalable. No se creará, reproducirá ni redefinirá la metodología o el contenido intelectual del cliente.

La base contiene actualmente aproximadamente 388 registros analíticos principales, organizados por materias y subcategorías, además de información relacionada que deberá preservarse durante la migración. El cliente proporcionará un archivo Excel para el desarrollo.

03 — Arquitectura técnica

Cómo se construye

Frontend

Next.js (App Router) + TypeScript + Tailwind. Renderizado en servidor por defecto: el contenido nunca viaja como JSON abierto al cliente, lo que protege el activo del cliente y da la mejor lectura en móvil.

Backend

Supabase — Postgres, Auth y Storage. La lógica de acceso vive en RLS, no en el frontend.

Hosting

Vercel. Dominio propio, SSL automático, previews por rama para la validación del Draft.

Búsqueda

Postgres nativo: tsvector + GIN, pg_trgm, unaccent. Sin servicio externo — a 388 registros no se justifica y evita un costo recurrente más.

Autenticación

Supabase Auth, correo + enlace mágico y contraseña. Sesión en servidor.

Pagos

Stripe Checkout + webhook firmado que escribe en entitlements. El acceso lo concede la base de datos, nunca el navegador.

Importación

Script Node con exceljs → staging → informe de validación → upsert idempotente. Ejecutable tantas veces como haga falta.

Admin

Panel propio dentro de la misma app, con rol editor, historial en audit_log y exportación a xlsx/csv.
